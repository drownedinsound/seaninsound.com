# Lessons

- Grey hex colours turn up in upper case (`#CCCCCC`) as well as short form (`#ccc`). Grep case-insensitively and for rgba whites too.
- Inline styles in the HTML bypass `style.css`. Sweep both.
- Moving a page changes a URL that may already have been shared. Ask first.
- Images in `assets/` should be under about 300KB and no wider than 1600px.
