# Fonts: what we use, where it comes from, and what is in this folder

**No font files are in this folder.** The fonts are licensed. Please do not ask for the files: get your own licence, or use the web delivery below.

| Role | Font | Where it is used | How to get it for the web | In this folder? |
|---|---|---|---|---|
| Display titles on SHOWNOTES cards and the map site | Druk XX Cond Super | Card titles, map site headings, DiS logo artwork | Self-hosted on the live map site (`map/fonts/Druk-XXCondSuper.woff2`). The original designer confirmed a web licence. | No |
| Body text, subtitles and credits (SHOWNOTES and DiS, from 2 Nov 2026) | Abril Text (Regular, Italic, SemiBold Italic, Bold) | Body copy, video subtitles (Bold), pink italic credits and asides | Adobe Fonts web project "SHOWNOTES map": `https://use.typekit.net/ulr4flt.css` | No |
| Labels and numbers (SHOWNOTES) | Flash SB / LTC Flash | Section labels, numbers | Same Adobe Fonts project (LTC Flash) | No |
| Headline faces in the magazine | BT Super Seventy, Becker Gothics Concave, Megascope, Buxom, Emfatick NF, Gikit | One per feature. Print only | Not for web | No |
| Video headlines (new look, from 29 Oct 2026) | Alternate Gothic No2, capitals | Podcast video titles | Licence source to be confirmed | No |
| Legacy DiS | Francois One (headlines, capitals), Cardo (body) | Old Instagram carousels. Being retired | Google Fonts, open licence | No (Google Fonts) |
| Free stand-ins until the real files are cleared | Abril Fatface (headlines), Playfair Display (reading text, closest free match to Abril Text) | Mock-ups and this kit's own pages | Google Fonts, open licence | No (Google Fonts) |

Fallback for Druk on the web: League Gothic Condensed (already set up in the Adobe Fonts project).

Do not use grey text on dark backgrounds. Body text never smaller than 16 px.
